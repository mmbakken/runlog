# Runlog server app

The back-end portion of the Runlog application. This is a simple Node/Express
app that runs Nodemon for hot-refresh. It uses MongoDB for its database.

## Getting Started

1. Install Node locally with `nvm`
2. Install PNPM locally.
3. Run `$ pnpm i` to install dependencies.
4. Run `$ pnpm serve` to start the server.
5. Make sure the Runlog Client is running (see `../client`).
6. Navigate to `localhost:3000`.
