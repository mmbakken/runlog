# Runlog client app

The front-end portion of the Runlog application. This is a single-page React app
that runs Vite for its development server and build tooling.

## Getting Started

1. Install Node locally with `nvm`
2. Install PNPM locally.
3. Run `$ pnpm i` to install dependencies.
4. Run `$ pnpm dev` to start the dev server with HMR.
5. Make sure the Runlog API is running (see `../server`).
6. Navigate to `localhost:3000`.
